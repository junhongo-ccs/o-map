# 今昔東京往来便覧（こんじゃく とうきょう おうらい びんらん）PoC

出発地と目的地を（一覧から選ぶ。一覧は現在の6路線の駅と、その駅から1km以内の明治の地名に限る）指定すると、**現在** と **明治18年（1885）** の東京での移動手段・経路・所要時間を並べて表示する。
背景は現在の地図（地理院地図）と迅速測図（1880年代）の **スワイプ比較 / 重ね合わせ（透過）**。

## 起動

```bash
npm install
npm start          # http://localhost:8787
npm test           # 経路計算・データ整合性・AI出力チェックのテスト
```

AI解説を使う場合は、起動前に環境変数 `ANTHROPIC_API_KEY` を設定する。未設定でも動作し、解説は「事実カード＋計算結果」から作る定型文になる。

## 公開（GitHub Pages）

main に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテストを通したうえで `public/` を GitHub Pages に公開する：https://junhongo-ccs.github.io/o-map/

静的な公開なので AI 解説は使えず、「AIで解説を生成」ボタンは表示されない（画面は起動時に `/api/status` を確かめ、AI が使えるときだけボタンを出す）。AI 解説を公開で使う方法は doc/tasks.md の7。

| `ai-guard.mjs` | AI入出力のチェック：事実カードをサーバー側のデータから引き直し、AIの文章に入力にない数値が含まれていたら解説を破棄する |

## 企画書のAI要件との対応

| 要件 | 実装 |
|---|---|
| 歴史解説・交通手段説明・地名解説をする | 経路計算の結果と事実カードだけを入力に、3つの見出し（なぜこの経路か／当時の交通事情／沿線の見どころ）で解説を生成 |
| 歴史を推測しない | 事実カード以外の知識で補わないよう指示し、引用したカードのIDを返させる |
| 根拠不明の所要時間を出さない | 所要時間はすべてエンジンが計算する。AIの文章に入力にない数値があれば破棄する（`ai-guard.mjs`） |
| 架空のルートを作らない | 経路はネットワークデータ上の探索結果だけ。AIは経路を作らない |

## 所要時間の計算

`距離 × 迂回係数 ÷ 速度 ＋ 待ち時間` で計算する。変えられる前提値（待ち時間・始発・終発・徒歩の速度）は「設定」の「計算設定」に、根拠と状態つきで表示する。

汽車と鉄道馬車で、乗車時間・待ち時間の求め方が違う。

- **汽車**（`line.timetable`）：明治18年5月刊の時刻表『鉄道汽車便覧表』（松永武英編、松陰堂。[NDL pid/805377](https://dl.ndl.go.jp/pid/805377)、パブリックドメイン）から転記した列車ごとの発着時刻を使う。画面で指定した出発時刻より後に駅を出る列車にだけ乗れ、その日の列車が終わっていれば使わない。急行の通過駅（上野発8:45の王子など）では乗り降りできない
  - 品川線（新橋–赤羽 直通）：1日4往復、75分（コマ14–16）
  - 官設鉄道（新橋–品川）：旅客列車1日15往復（コマ16–20。新橋・品川の時刻のみ）
  - 日本鉄道（上野–赤羽）：旅客列車1日4往復（コマ12–14。上野・王子・赤羽の時刻のみ）
  - 貨物列車は除いた。上り列車の新橋・上野の時刻は「着」、赤羽は「發」（資料の注記による）
- **鉄道馬車**：速度から乗車時間を出し、平均待ち時間の仮定値（スライダーで変更可）を足す。運行時間（始発7:00・終発20:00、いずれも仮定値）の外では、始発前なら始発まで待ち、終発後は乗れない。現在の電車も同じ扱い（始発5:00・終電24:00の仮定値）

前提値の状態は次のとおり。

- **出典あり**：汽車の発着時刻（当時の時刻表）、鉄道馬車の速度（新橋→浅草広小路 46分から算出）、現在の徒歩速度（80m/分）
- **仮定**：明治の徒歩速度（4km/h。旅の1日の歩行距離からの換算で、市街地の速度を示す資料は未入手）、鉄道馬車・現在の電車の待ち時間と運行時間（始発・終発）、迂回係数

汽車は1日4往復しかない路線が多いため、出発時刻で最速経路が入れ替わる。例：渋谷→浅草は、11時半発なら品川線で赤羽へ北上して上野行きに乗り換え、鉄道馬車と合わせて2時間19分。9時発だと汽車を待つより大山道・甲州街道を歩いて鉄道馬車に乗る方が早く、2時間42分。

## 運賃（明治18年）

明治の経路には、当時の運賃を銭（100銭＝1円）で出す。下等を主に、中等・上等を添える。

- **汽車**：『鉄道汽車便覧表』の運賃表から、アプリで使う駅の間の運賃を転記した（`fares`）。日本鉄道の中で乗り継ぐとき（品川線 → 赤羽 → 上野など）は通し運賃。品川線で新橋から乗るときは、新橋–品川の官設鉄道の運賃を足す（資料に通し運賃がないための仮定）。照合用の一覧は [doc/fares-1885.md](doc/fares-1885.md)
- **鉄道馬車**：1区あたり1等3銭・2等2銭（Wikipedia）。区の区切りが分からないため、1回乗るごとに「2銭〜」と最低額で出す
- 現在の運賃は出さない

## 既知の制約（PoCとして割り切った点）

- 1885年の駅・街道の位置は、現在の地名・駅位置からの近似。街道は主要な通過点を結んだ折れ線
- 甲州街道の日本橋〜半蔵門、赤坂見附〜新橋、須田町〜上野は経路が不確かな「市街路（近似）」
- 汽車の時刻表は明治18年5月のもの。年の途中の改正はモデルに入れていない
  - 品川線は開業時（3月1日実施）には3往復で、時刻も違った（官報 第499号、明治18年3月4日。目黒・目白の時刻も載っている）
  - 11月1日の改正（官報 第700号、明治18年10月29日）で、品川線は4往復のまま新橋–赤羽が60分に短縮された。日本鉄道（上野–前橋・宇都宮）の時刻も同時に改正されている
  - 日本鉄道は7月に大宮–宇都宮間が開業し、「上野前橋間大宮宇都宮間汽車発着時刻並乗車賃金表」（明治18年7月）が出ている（JTB交通博物館の所蔵リスト。原本未確認）。上野–赤羽の時刻が変わった可能性がある
- 時刻表は画像から読み取って転記した（Claude による読み取り。アプリで使う5月の3表は 2026-10-02 に人が画像と照合済み）。午前・午後は各表の凡例による。照合用の一覧は [doc/timetables-1885.md](doc/timetables-1885.md)
- 乗り換えに必要な時間は見ていない（同じ駅で、着いた時刻と同時刻に出る列車にも乗れる扱い）
- 鉄道馬車の1885年の運転間隔・始発・終発は未入手（始発・終発は仮に7:00・20:00としている）
- 現在のモデルは6路線のみで、実際より遅く出ることがある
- 事実カードの多くは「未照合」（Wikipedia等の二次資料。一次資料での照合が未了）
- 数値チェックの対象は算用数字（全角を含む）と、助数詞が続く漢数字（「十里」「明治十八年」など）。助数詞のない漢数字や「十分（じゅうぶん）」と読める表記は検出しない

## 次の一手の候補

1. 鉄道馬車の1885年の運行（運転間隔・始発・終発）を調べ、平均待ち時間の仮定を置き換える。手がかり：白石弘之『東京馬車鉄道』（都史紀要33、1989）、『都史資料集成 第3巻 東京市街鉄道』、工部省記録（鉄道之部）
2. 迅速測図・五千分一東京図測量原図（1880年代、参謀本部）から街道・主要道をデジタイズし、「近似」区間をなくす。五千分一東京図は PMTiles が [source.coop/wata909/historical-topomaps-jp](https://source.coop/wata909/historical-topomaps-jp) にあるが、ライセンスの記載がないため利用前に確認が必要
3. 事実カードを一次資料（鉄道史・区史）で照合し、「確認済」に上げる
4. 時代を追加（例：1910年の市電、1930年代の地下鉄）
