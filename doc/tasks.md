- アプリ名は「今昔東京往来便覧」。GitHub Pages で公開中：https://junhongo-ccs.github.io/o-map/ （main に push すると、テストを通ったうえで自動で公開し直される）
- 明治の汽車3路線（品川線・官設鉄道 新橋–品川・日本鉄道 上野–赤羽）の時刻は、明治18年5月刊『鉄道汽車便覧表』（NDL pid/805377）から転記。3路線とも人による照合済（2026-10-02、全件一致）。照合シートは [timetables-1885.md](timetables-1885.md)
- 汽車の運賃も同書から転記。官設鉄道（新橋–品川）は人による照合済。日本鉄道の9駅分は人による照合はしないことにした（Claude の読み取りと、行き帰りの一致・赤羽経由の加算の機械チェックのみ）。照合シートは [fares-1885.md](fares-1885.md)
- 鉄道馬車の待ち時間・始発・終発、徒歩速度、迂回係数は仮定値（設定ページで変えられる）
- 現在の側は6路線の簡略モデル（山手線・中央線快速・銀座線・丸ノ内線・京浜東北線 上野–赤羽・埼京線 池袋–赤羽）
- 出発地・目的地は一覧から選ぶ（現在の6路線の駅と、その駅から1km以内の明治の地名）。自由入力・地図クリックはやめた
- 名所は29か所（西18・東11。2026-10-05 に東側の浅草・上野東照宮・昌平橋・両国橋・富岡八幡宮を追加）。ピンの代わりに吹き出し型のラベル、押すとカード（浮世絵・錦絵の画像、事実カード、目的地・出発地ボタン）。画像の権利とクレジットは `public/data/spot-images.json`
- 右の結果の欄（スマホではボトムシート）は、上に「所要時間の比較」を固定し、その下の横一列のチップ（当時の経路・現在の経路・沿線の見どころ・解説・根拠）で中身を切り替える（2026-10-05、アコーディオンから変更）。チップの列は下にスクロールしても上に貼りつき、ボトムシートの「半分」は必ずチップの列まで見える高さにする
- 「汽車・馬車を優先」（既定でオン）：駅で長く待っても、歩く時間がなるべく短い経路を出す（歩く1分を待つ4分ぶんと数える。`router.js` の walkWeight、`app.js` の WALK_WEIGHT = 3）。出発時刻は変えず、待ち時間は所要時間に入る。最初の駅で長く待つときは「出発を NN:NN に遅らせても間に合う」と案内する（2026-10-05 変更。前は「乗り物を1回以上使う経路のうち最速」で、ほとんど歩く経路が出ていた）
- 解説は定型解説のみ（事実カードと計算結果だけから組み立てる）。AI 解説のコードは手元の `npm start` でだけ動き、公開版ではボタンを隠している。Dify への接続は見送り（下の 5）
- 外部LLMの調査レポートは `doc/report-*.md`（誤りを含む作業メモ。GitHub には公開せず手元だけ）
- テスト：`npm test`（26件、すべて通過）
- graphify でコードと文書のナレッジグラフを作成済（`graphify-out/`、git の対象外）。変更後は `/graphify --update` で作り直せる

### 2-3. 時刻表の「時期」切り替えを入れるか決める

品川線には3月・5月・11月の時刻表がある（3月：官報 第499号、11月：官報 第700号。照合シートに転記済、アプリは5月のみ）。

- [ ] 入れるかどうか決める。入れる場合、官報 第700号の日本鉄道（上野–前橋・宇都宮）の11月の表の転記が必要。官設鉄道は11月の資料がないので、5月を流用するか、11月を選べないようにするかも決める
