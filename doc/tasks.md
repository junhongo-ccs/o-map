### 5. 鉄道馬車の1885年の運行を調べる

どの外部LLMのレポートでも見つからなかった。図書館での調査が必要。

- [ ] 『東京市史稿 市街篇第82』858頁付近（明治18年の車両62両・馬425頭の統計の出典。運行についての記述も近くにある可能性）
- [ ] 白石弘之『東京馬車鉄道』（都史紀要33、東京都、1989）
- [ ] 『都史資料集成 第3巻 東京市街鉄道』
- [ ] 工部省記録（鉄道之部）第20巻「東京馬車鉄道会社一件」（国指定重要文化財）
- [x] 『東京市電気局三十年史』（東京市電気局、1940）11〜15頁（読了 2026-10-02、画像0057〜0059）。12頁に開業当時（明治15年）の「全線に三十臺若くは四十臺の車輛を運轉」「乗客定員は二十四人乃至二十七人、馬匹二頭牽引、乗務員は馭者・車掌各一名」。14頁に明治35年末の「一時間に六十七臺乃至七十臺即ち一分時間に一臺以上の發車運轉」。始発・終発、停留場の記述はない。東京都立図書館デジタルアーカイブでインターネット公開（パブリックドメイン）：[資料1](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00040198)・[資料2](https://archive.library.metro.tokyo.lg.jp/da/detail?tilcod=0000000009-00040199)
- [ ] 小熊米雄「東京都電前史（上）」『鉄道ピクトリアル』121号（1961）16〜23頁。車両の大きさ・定員の出典
- 参考（読了 2026-10-02）：青木栄一『都市化の進展と鉄道技術の導入』（国連大学 人間と社会の開発プログラム研究報告、1982）5〜9頁。[PDF](https://d-arch.ide.go.jp/je_archive/pdf/workingpaper/unu_jpn65.pdf)。1885年の運転間隔・始発・終発の記述はない。1902年末は「馬車約300両、馬匹2千余頭、多客区間では1分以下の間隔で運転」。上の2つはこの論文の注に挙がっている出典
- 知りたいこと：運転間隔（何分おき）、始発・終発、停留場の位置（どこでも乗り降りできたかどうか）、運賃の区の区切り（1区はどこからどこまでか。今は1回乗るごとに1区分の2銭〜で計算している）
