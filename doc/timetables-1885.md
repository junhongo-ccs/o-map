# 明治18年 時刻表の転記・照合シート

アプリの汽車の時刻（`public/data/network-1885.json` の `timetable`）は、下記の資料の画像から Claude が読み取って転記したものです。**アプリで使う5月の3表（1〜3）は 2026-10-02 に人が照合済み。参考の3月・11月の表は未照合です。** 各表の「資料」のリンクから画像を開き、数字を見比べて、合っていれば「照合」欄に名前と日付を書いてください。食い違いがあれば、その場所と正しい値を書き添えてください。

時刻はすべて24時間表記に直してあります（資料は12時間表記で、午前・午後は各表の凡例による）。

## 読むときの注意

- 『鉄道汽車便覧表』の品川線の表は、**下り4本が右から左へ**（例：「分五十四時七」＝7時45分）、**上り4本が左から右へ**印刷されている。読み違えやすいので特に注意
- 『鉄道汽車便覧表』の新橋–横浜の表は、列車が列（縦）、駅が行（横）の向きになっている
- 上り列車の新橋・上野の時刻は「着」、赤羽は「發」（資料の注記）
- 貨物列車（表中「貨物」）は転記していない
